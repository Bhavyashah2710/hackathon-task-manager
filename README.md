# Hackathon Task Manager 🚀

A web-based task management platform designed to help hackathon teams organize, assign, and track tasks efficiently during competitions.

## Features

* ✅ Create and manage tasks
* 👥 Assign tasks to team members
* 📊 Track task progress
* ⏰ Monitor deadlines
* 📋 Organize hackathon workflow
* 🔄 Update task status in real time

## Tech Stack

* Python
* Flask
* Django
* HTML
* CSS
* JavaScript

## Project Goal

Hackathon teams often struggle with task distribution and progress tracking under time constraints. This project helps teams stay organized by providing a centralized platform for managing responsibilities and monitoring project progress.

## Installation

1. Clone the repository

```bash
git clone https://github.com/Bhavyashah2710/hackathon-task-manager.git
```

2. Navigate to the project folder

```bash
cd hackathon-task-manager
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```
